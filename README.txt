THE PLAYGROUND PRESS - ISSUE 003: THE 11:47 PARADOX

RENDER STATIC SITE DEPLOYMENT
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Render choose New > Static Site and connect the repository.
4. Branch: main
5. Root Directory: leave blank
6. Build Command: leave blank
7. Publish Directory: .
8. Create Static Site.

No backend or build step is required.

Files:
- index.html: interactive magazine
- issue-003.pdf: matching printable edition with answer key
- puzzle-data.json: puzzle verification data
