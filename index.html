The night the clocks disagreed

At 11:47 PM, researcher Dr. Ira Sen disappeared from Lab 3 of the Astra Time Institute. The magnetic lock reports no opening. The corridor camera has a gap. The institute's clocks disagree by several minutes.

PUZZLE 01 · ROUTE FINDING

The lockdown maze

Start at M (top-left) and reach R (bottom-right). Move only through openings between adjacent squares. Pass checkpoint A, then checkpoint B, in that order. No diagonal moves and no revisiting cells. This is a perfect maze, so there is exactly one route.

Click cells in travel order. The route must begin at M, pass A then B, and finish at R. The exit plaque reads RIFT. Record its first letter.

Select M first, then each adjacent cell.

Never cross a thick wall. Checkpoint letters are printed inside ordinary cells.

If you reach a dead end, backtrack to the last junction. The route is unique.

PUZZLE 02 · NUMBER LOGIC

The time grid

Complete the 9×9 Sudoku. Every row, column and 3×3 box contains digits 1–9 exactly once. Extraction cell: R2C4 (row 2, column 4). Convert its solved digit using 1=A, 2=B … 9=I.

Start with rows and columns that already contain the most numbers. Use pencil candidates.

Look for a digit that has only one possible position inside a 3×3 box.

FINAL PUZZLE · META EXTRACTION

Open the master log

Enter the six letters in order, from Puzzle 01 to Puzzle 06. The password is a command, not a person's name.

MASTER LOG UNSEALED

REWIND. The clock synchronisation service was altered at 11:47 using Dev Malik's administrator token D-17. The door controller records no physical unlock. The disappearance was made to look impossible by shifting the displayed timeline, not by opening a magically locked door. Dev's denial is contradicted by the console audit.

Case closed. Dev altered the clock record to conceal unauthorised access to the calibration console.
